Каскадная переадресация портов


Описание


Скрипт автоматизирует настройку каскадной переадресации портов на Linux-сервере с использованием iptables. Позволяет создать промежуточный сервер (мост) для туннелирования трафика между клиентами и удаленными VPN/прокси-серверами.


Основные возможности
Поддержка протоколов: UDP (WireGuard/AmneziaWG) и TCP (VLESS/XRay)

Управление правилами: Добавление, удаление, просмотр и сохранение правил iptables

Автоматизация: Автоматическое создание правил переадресации и MASQUERADE

Сохраняемость: Все правила сохраняются в файл и восстанавливаются при перезагрузке

Резервное копирование: Автоматическое создание резервных копий конфигураций

Systemd служба: Возможность создания службы для автозагрузки правил при старте системы

Улучшение производительности: Автоматическая активация BBR (TCP congestion control)

Для кого предназначен
Администраторы, настраивающие VPN/прокси-сервера

Пользователи, которым нужна дополнительная обфускация трафика

Те, кто хочет использовать промежуточный сервер для туннелирования

Поддерживаемые сценарии использования
WireGuard/AmneziaWG каскад: Клиент → Этот сервер → Удаленный WireGuard сервер

VLESS/XRay каскад: Клиент → Этот сервер → Удаленный прокси-сервер

Любая другая переадресация UDP/TCP трафика

Основные особенности
Цветной интерфейс: Удобное меню с цветовой разметкой

Проверка прав: Автоматическая проверка прав root

Валидация ввода: Проверка корректности вводимых данных

Отказоустойчивость: Обработка ошибок и восстановление

Документация: Встроенная инструкция по настройке

Требования
Операционная система: Linux (тестировалось на Ubuntu/Debian)

Права доступа: Требуются права root

Установленные пакеты: iptables, systemd

Сетевой интерфейс: Настроенное сетевое подключение

Структура файлов
/etc/iptables/rules.sh - Основной файл правил

/etc/iptables/rules.sh.backup - Резервная копия

/etc/systemd/system/load-iptables-rules.service - Служба автозагрузки (после создания)

Выход

Принцип работы
Скрипт получает IP и порт целевого сервера

Создает DNAT правило для переадресации трафика

Настраивает правила FORWARD для фильтрации

Активирует MASQUERADE для преобразования адресов

Сохраняет все настройки в файл для последующего восстановления

Преимущества использования
Упрощение настройки: Все сложные команды iptables выполняются автоматически

Надежность: Правила сохраняются и восстанавливаются после перезагрузки

Безопасность: Минимальные необходимые правила, без излишнего открытия портов

Гибкость: Легкое добавление и удаление правил через меню

Внимание!
Скрипт требует прав root для работы

Изменяет системные настройки сети

Рекомендуется использовать на чистых серверах или делать бекап текущих настроек

После настройки необходимо изменить endpoint в клиентском приложении на IP этого сервера
